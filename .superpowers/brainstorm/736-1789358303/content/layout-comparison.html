🎬 Về Cấu Trúc Video Nhiều Câu Hỏi (Multi-Round)

Chúng tôi đề xuất hỗ trợ 2 chế độ linh hoạt cho bạn lựa chọn:

  • Chế độ 1 câu (Single-Quiz ~15-18s): Hook 2s → Game All-in-One 10s (suy nghĩ + đếm ngược 5s + reveal 3s) → CTA 3s. Tối ưu cho thuật toán lướt nhanh TikTok.
  • Chế độ 3 câu liên tiếp (Multi-Round ~35-45s): Hook 2s ("Thử thách 3 câu!") → Vòng 1 (10s) → Vòng 2 (10s) → Vòng 3 (10s) → Bảng điểm & CTA 3s. Tối ưu cho comment spike ("Ai đúng cả 3 câu giơ tay?").
