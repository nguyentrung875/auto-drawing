- (decision) AD-1 Paradigm: Pipes-and-Filters — mỗi video chạy qua pipeline 5 giai đoạn tuần tự (Plan→TTS→Draw→Compose→Encode), mỗi giai đoạn là một filter độc lập. Prevents: hai dev xây filter bằng interface khác nhau, tạo coupling.
- (decision) AD-2 Language: TypeScript (Node.js) toàn bộ. Motion Canvas đã là TS, FFmpeg gọi qua child_process. Prevents: polyglot drift Python/TS.
- (decision) AD-3 TTS Engine Interface: Adapter pattern — ITtsEngine interface, default impl dùng Piper archived MIT release. Prevents: hard-code TTS engine, khó swap.
- (version) Piper TTS: active branch chuyển sang GPL-3.0 (OHF-Voice/piper1-gpl v1.7.0). Archived rhasspy/piper MIT vẫn dùng được nhưng không có updates. PRD A-01 cần cập nhật risk.
- (decision) AD-4 Registry: JSON files on disk, loaded at startup. Single writer (CLI/ingestion tool), nhiều reader (pipeline workers). Prevents: DB dependency, concurrent write conflicts.
- (decision) AD-5 Rendering: Motion Canvas headless mode → frame sequence → FFmpeg mux. Prevents: browser GUI dependency, non-deterministic render.
- (decision) AD-6 State mutation: Pipeline state là immutable data flowing qua filters. Mỗi filter nhận input, trả output mới. Side effects chỉ ở đầu (read Registry) và cuối (write file). Prevents: shared mutable state giữa filters.
- (decision) AD-7 Batch orchestration: Worker pool pattern — N workers = CPU cores, mỗi worker chạy 1 pipeline instance. Queue manager phân phối concepts. Prevents: memory overflow, uncontrolled parallelism.
- (decision) AD-8 Error boundary: Mỗi filter trả Result<T, PipelineError>. Batch mode: lỗi 1 concept không crash toàn batch — ghi log, đánh dấu failed, tiếp tục. Prevents: silent failures, batch crash.
- (decision) AD-9 Seed determinism: Seed được inject ở đầu pipeline, truyền qua mọi filter. Mọi randomness (diversification, timing jitter) phải dùng seeded PRNG. Prevents: non-reproducible output.
- (decision) AD-10 Hand Engine contract: HandController nhận PathSegment[], trả HandFrame[] (position, rotation, scale, opacity per frame). Prevents: coupling giữa drawing geometry và hand rendering.
